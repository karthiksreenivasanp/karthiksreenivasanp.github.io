Sign in to write

Posts are saved straight to your GitHub repo, so this needs a GitHub token that can write to it. The token stays in this browser and is only sent to GitHub.

  1. Open GitHub → New fine-grained token.
  2. Repository access: Only select repositories → your site repo.
  3. Permissions → Repository → Contents: Read and write.
  4. Generate, copy and paste it below.
