Projects

Knee Acoustic Detection · Application

AI/ML · Web

Developed a machine learning-driven web application focused on analyzing joint sounds (JAE/VAG signals) to detect knee abnormalities. The system integrates a predictive classification model trained in Python with a lightweight HTML, CSS, and JavaScript frontend. Deployed on Vercel, the application provides a seamless, accessible interface for real-time acoustic signal processing and reliable knee health assessments.

ParkXplore · Intelligent Parking Space Detection

Computer Vision

Developed a real-time computer vision system for automated parking space management leveraging a fine-tuned RT-DETR (Real-Time Detection Transformer) model. Engineered an interactive, point-based graphical tool using Python and OpenCV that allows users to map valid parking slots on reference images. The system evaluates overlaps against mapped points to classify spaces as occupied or free, supports scalable batch processing, and outputs dynamically annotated visuals and summary overlays to optimize space allocation.

Speaker-Based Attendance System

Voice Biometrics

Architected a full-stack, real-time voice recognition application that automates student attendance tracking. Built a backend with Python and FastAPI, integrating SpeechBrain and a fine-tuned ECAPA-TDNN model for audio embeddings and speaker verification. Created a React + Vite dashboard for enrollment, browser microphone recording, and attendance monitoring. Uses SQLite for secure storage, includes noise removal/signal processing pipelines, and secure remote tunneling via Ngrok.

Litloom · Digital Poetry Analysis Application

NLP · Desktop

Engineered a desktop-based poetry analysis app using Python and Tkinter. Integrates NLP via NLTK to detect rhyme schemes, parse parts of speech, identify figures of speech, and run VADER sentiment analysis. Includes a custom-themed UI with spell-checking, multi-language translation (deep-translator), TTS via Windows SAPI5, and a ReportLab export module to generate formatted PDF reports.
